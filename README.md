# Melo-MPD Support

Official support for the Melo-MPD suite of MPD clients for macOS and iOS.

## Get help

- 🐛 **Bug reports** → [Open an issue](https://github.com/Melo-MPD/support/issues/new/choose)
- 💡 **Feature requests** → [Open an issue](https://github.com/Melo-MPD/support/issues/new/choose)
- 💬 **Questions** → [Discussions](https://github.com/Melo-MPD/support/discussions)
- ✉️ **No GitHub account?** → Email melo-support@your-domain.example

## Before reporting a bug

Please include your app version, OS version, MPD server version
(`mpd --version`), and how you connect (LAN, VPN, proxy, TLS).
